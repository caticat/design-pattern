# 创建型模式

关注**怎么创建对象**：把「创建什么、怎么创建」从使用方剥离出去，让代码不依赖具体类型。

| 模式 | 解决的问题 |
|---|---|
| [单例](singleton/index.md) | 某个对象全局只能有一个 |
| [工厂方法](factory-method/index.md) | 使用产品的流程固定，创建方式要能替换 |
| [抽象工厂](abstract-factory/index.md) | 需要成套创建彼此配套的对象 |
| [建造者](builder/index.md) | 构造参数多、步骤复杂 |
| [原型](prototype/index.md) | 从零创建代价高，复制更便宜 |

工厂方法关注**谁决定怎么造**；抽象工厂关注**一组产品怎么保持配套**；建造者关注**一个复杂对象怎么一步步组装**。
