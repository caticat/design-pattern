# 10.4 小结

## 重点回顾

!!! takeaway "划重点"
    - 组合 = **叶子和组合实现同一接口**，组合的子节点也是这个接口。
    - 组合把工作交给子节点再汇总，一层层递归，直到叶子。
    - 调用方只依赖接口，单个对象和整棵树用法相同。

## Q & A

**Q**：叶子要不要也实现 `Add`？

Go 里一般不要。把 `Add` 只放在组合类型上，文件误调 `Add` 直接编译不过。两种做法的对比见 [10.3](stdlib.md)。

**Q**：子节点需要知道自己的父节点吗？

本例不需要。要显示完整路径或往上找时，可以给节点加一个 `parent *Dir` 字段，但要在 `Add` 和移动节点时同步维护，容易出错，能不加就不加。

**Q**：树很大时，每次 `Size` 都从头算，会不会慢？

会。可以在目录里缓存结果，子节点变化时把缓存连同所有上层目录一起作废。先确认真的慢再加，缓存是最容易出错的地方。

**Q**：组合和装饰器都持有同一接口的对象，区别在哪？

装饰器只包**一个**对象，在它的结果上多做点什么；组合持有**多个**子节点，把它们的结果汇总起来。
